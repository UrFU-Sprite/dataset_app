# DataLake Platform

Централизованное хранилище данных с распределенной архитектурой на базе MongoDB, PostgreSQL, ClickHouse и MinIO.

## Архитектура

- **MongoDB** - полуструктурированные данные (проекты, задачи, профили)
- **PostgreSQL** - структурированные данные (пользователи, финансы, метрики)
- **ClickHouse** - аналитические данные (логи, события, временные ряды)
- **MinIO** - объектное хранилище (файлы, изображения, экспорты)
- **Redis** - кэширование и очереди
- **FastAPI** - бэкенд API
